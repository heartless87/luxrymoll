# 🛍️ LuxryMoll – Modern Shopping Website

LuxryMoll is a modern, responsive shopping website built using **HTML, CSS, JavaScript**, and a **MongoDB + Vercel backend**.  
Products are dynamically loaded from a serverless API and stored in a cloud database.  
Admins can add new products with images (Base64 encoded) through a secure form.

## ✨ Features

### 🛒 Customer Features
- Infinite scroll product listing
- Product cards with images, pricing & discount style
- Auto pagination system
- Smooth loading animation
- Responsive layout for all screen sizes
- Click product → open product details page

### 🧑‍💻 Admin Features
- Add new products through a secure form
- Upload **1–7 images**, auto-converted to Base64
- Images stored as `image-1`, `image-2`, etc.
- Add product title, description, prices
- MongoDB Atlas integration
- Instant update to the store after adding new product
